# Изменения

## Unreleased

## 0.1.5 — 2026-10-30

- Daily и игры имеют отдельные состояния проверки; неизвестный игровой результат больше не выключает ежедневный автосбор.
- Неопределённый daily проверяется чтением статуса с паузой от 5 минут до 6 часов, без повторной отправки начисления.
- Ответ daily распознаётся по явному `rewardInfo`, включая наблюдённый статус `REWARD_NOT_AVAILABLE` после успешного начисления.
- Миграция `0004` добавляет состояния восстановления; старые отключённые аккаунты не включаются автоматически.

- Единое оформление создания аккаунта, QR-входа, ошибок и подтверждений.
- Утверждённое оформление QR: Liquid, единый графитовый цвет и монохромный знак Маркета в центре, без монеты и цветных акцентов.


## 0.1.4 — публикация отменена

- Брендированный QR входа: скруглённые модули и маркеры, цветовые акценты и монета Маркета в центре.
- Повышена коррекция ошибок QR до H, сохранено свободное поле в четыре модуля. Изображение монеты загружается из локального ресурса без сетевых запросов при входе.
- Сохранён оригинальный SVG-логотип Маркета и указаны источники изображений.

## 0.1.3 — 2026-10-30

- Результаты обновления баланса, сбора daily, игровых наград и проверки входа открываются отдельным экраном с кнопкой «Назад к аккаунту».
- Возврат отображает актуальную карточку выбранного аккаунта без повторного запуска операции.

## 0.1.2 — 2026-10-30

- Явные имена production-контейнеров: `ymf-prod-bot`, `ymf-prod-db`, `ymf-prod-migrate`, без числовых суффиксов.
- Префикс соответствует Compose project name, поэтому тестовые запуски остаются изолированными.

## 0.1.1 — 2026-10-30

- Исправлен YAML tmpfs в production Compose: опции монтирования передаются одной строкой.
- Повторный запуск установщика исправляет эту ошибку в Compose v0.1.0 с резервной копией, не меняя секреты и данные.
- CI проверяет запуск production Compose, миграции и права контейнера с изолированной тестовой БД.

## 0.1.0 — 2026-10-30

### Возможности

- Установка одной командой `bash <(curl …)`: только Compose, `.env`, сессии и готовый образ из GHCR.
- Bash-установщик для Ubuntu/Debian: последний стабильный релиз, Docker, приватная конфигурация и запуск без сборки на VPS.

- Личный Telegram-бот с QR-входом, несколькими аккаунтами и inline-меню.
- Чтение баланса, отдельные операции daily и заработанных игровых наград.
- Автосбор daily по времени API, история, блокировки и восстановление расписания.
- PostgreSQL / SQLModel / Alembic, Docker Compose, локальная диагностика.

### Подготовка публикации

- Обновлены Pillow до 13.0.0 и aiohttp до 3.14.5 по предупреждениям Dependabot.
- Исправлено экранирование PostgreSQL healthcheck для GitHub Actions runner.

- CI с PostgreSQL и проверкой Docker runtime; релизы по тегам и образы GHCR для amd64/arm64.
- Инструкции установки, обновления, резервного копирования и разработки.
