# План ядра

Цель: независимый синхронный клиент Python 3.13 с явными операциями, без серверной инфраструктуры.
Основание: требования пользователя и docs/api-research.md. Пользователь поручил автономный выбор решений.

- [x] Исследовать источники; документировать границы доказанности.
- [x] SessionStore: приватный Netscape jar, атомарное сохранение, эксклюзивная блокировка.
- [x] MarketClient: HTML-контекст, allowlist запросов, баланс, daily, hub/status/earned claim.
- [x] CLI: локальный импорт, read-only по умолчанию, явное включение claim.
- [x] Проверить pytest, ruff, сборку, CLI и провести независимый обзор.

Тесты сначала: истёкшие cookies, права/ссылки файлов, неверные схемы, отказ доступа,
429/Retry-After, отсутствие повторов мутаций, только достигнутые уровни, блокировка процессов.
Синтетические ответы реконструируются по Go-типам, не выдаются за реальные HAR.
Сеть недоступна из shell: зависимости устанавливаются offline из копии локального кеша.
Не переходить к БД/боту/VPS до проверки API настоящим аккаунтом.

Проверки и ограничения: ../../validation.md. Реальная авторизация и API не проверены; этап 5 отложен.
