# Конфигурация

[← Документация](README.md)

Настройки читаются из `.env` через Pydantic Settings. Схема — [.env.example](../.env.example).
Переменные окружения процесса имеют приоритет. После изменения конфигурации перезапустите приложение.
`make setup-env` создаёт файл, но не заменяет существующий.

| Переменная | Назначение |
|---|---|
| `BOT__TOKEN` | Токен вашего Telegram-бота |
| `BOT__OWNER_ID` | Положительный числовой ID владельца; не username |
| `POSTGRES__HOST` | Локально `127.0.0.1`; Compose переопределяет на `db` |
| `POSTGRES__PORT` | В примере `15432`; внутри Compose всегда `5432` |
| `POSTGRES__USER` / `POSTGRES__DATABASE` | Пользователь и база, по умолчанию `ymf` |
| `POSTGRES__PASSWORD` | Пароль БД; сгенерируйте случайное значение |
| `MARKET__SESSION_DIR` | Каталог cookies; Compose использует `/data/accounts` |
| `MARKET__INTERVAL_SECONDS` | Ограничение частоты HTTP-запросов; **не интервал автосбора** |
| `APP__DEBUG` | Отладочное логирование, обычно `false` |
| `APP__HEARTBEAT_FILE` | Файл heartbeat; в контейнере `/tmp/ymf/heartbeat` |
| `YMF_UID` / `YMF_GID` | UID/GID владельца каталога сессий на Linux |
| `YMF_IMAGE` | Полное имя опубликованного образа с версией или digest |

> [!CAUTION]
> Замена `POSTGRES__PASSWORD` в `.env` не меняет пароль внутри уже созданного PostgreSQL volume.
> Не удаляйте volume ради исправления конфигурации. Сохраните действующий пароль или измените его в БД отдельно.

Используйте `.env` с правами `600`, каталоги сессий — `700`. Не включайте debug-отчёты,
QR-ссылки, cookies или токены в публичные issues. Локальный и серверный запуск одного бота
не должны работать одновременно, даже если подключены к разным БД.
