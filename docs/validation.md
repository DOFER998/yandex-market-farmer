## Повторение проверок

```bash
make check
make test-postgres
```

`make check` не использует реальные credentials внешних API. PostgreSQL-тест по умолчанию
пропускается; `make test-postgres` включает его и работает во временной схеме существующей тестовой БД.
CI запускает его на отдельном PostgreSQL service container, без production-данных.
PNG-тест требует Pillow из `qrcode[pil]`; полный `make sync` устанавливает эту зависимость.

При развёртывании новой версии отдельно проверьте:

- [ ] Успешный CI и Docker smoke на GitHub, multi-platform публикацию в GHCR.
- [ ] QR-вход с IP сервера, сохранение сессии после перезапуска.
- [ ] Автосбор доступной daily по назначенному времени и запись результата в историю.
- [ ] Сбор положительной, реально заработанной игровой награды.
- [ ] Резервное копирование и восстановление на отдельной установке.
